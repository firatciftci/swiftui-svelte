# swiftui-svelte documentation

- [Getting started](getting-started.md): create an app from the template, or add swiftui-svelte to an app you already have.
- [Element reference](reference.md): every element and modifier, with the type of each attribute and an example.
- [Elements](elements.md): how the elements behave, from rich text, colors, and shapes to bindable components, refs and focus, transitions, presentations, and accessibility.
- [Navigation](navigation.md): navigation stacks and search.
- [Forms](forms.md): settings screens and sign-up forms, with text fields, keyboards, focus, and validation.
- [Loading data](loading-data.md): requests with loading and error states, pull to refresh, paging, saved data, and WebSockets.
- [Device environment, lifecycle, and localization](environment.md): the device's settings, app lifecycle events, deep links, restoring state, and translations.
- [Web APIs](web-apis.md): `fetch`, `WebSocket`, `localStorage`, and the other browser APIs that the app provides.
- [Native modules and components](native-modules.md): calling Swift from JavaScript, the built-in modules, and SwiftUI views as new elements.
- [Embedding in a Swift app](embedding.md): props, actions, several components in one bundle, and views that share one runtime.
- [Performance](performance.md): keeping the app fast, and how to measure it on a device.
- [Debugging](debugging.md): live reload, logging, Safari's Web Inspector, errors, and common problems.
- [Releasing to the App Store](app-store.md): release builds, versions, privacy, and testing before you submit.

The example app shows every element in its Catalog tab. [CONTRIBUTING.md](../CONTRIBUTING.md) explains how to run it.
